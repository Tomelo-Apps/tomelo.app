Ваші дані залишаються у вашому телефоні

Без акаунта, без хмари, без стеження, без реклами. Якщо застосунку не потрібен інтернет, він навіть не має дозволу ним користуватися. Це можна перевірити в налаштуваннях телефона.

Працює тоді, коли це важливо

Ми робимо застосунки для справжніх телефонів, зокрема для тих, що присипляють застосунки заради батареї. І ми покажемо крок за кроком єдине налаштування, яке потрібне вашому телефону.

Достатньо прості для кожного

Великі кнопки, зрозумілі слова і спрощений режим для тих, кому телефони даються важко. Зручно для всіх, зокрема для людей старшого віку та родин, які їм допомагають.

Одна оплата. Жодної підписки.

PillBell

Android · 10 мов

Нагадування про ліки, яке справді дзвонить: на весь екран, як будильник, доки ви не приймете дозу. Для всіх, хто не хоче пропустити прийом, чи то одні ліки, чи багато, і для тих, хто допомагає з ліками комусь іншому. Спрощений режим, уся родина в одному застосунку, PDF-список ліків для лікаря і запис кожного нагадування, яке задзвонило вчасно.
