O que cada aplicação Tomelo promete

Vale para todas as aplicações que fazemos, agora e no futuro.

Os seus dados continuam a ser seus

Sem conta, sem rastreio, sem anúncios. Uma aplicação liga-se à internet apenas quando a sua tarefa o exige, por exemplo para a meteorologia, e nunca envia os seus dados para lado nenhum. Quando uma aplicação não precisa de internet, nem sequer tem permissão para a usar. Pode verificá-lo nas definições do telemóvel.

Funciona quando é importante

Fazemos aplicações para telemóveis reais, incluindo os que adormecem as aplicações para poupar bateria, e mostramos-lhe passo a passo a única definição de que o seu telemóvel precisa.

Simples para qualquer pessoa

Botões grandes, palavras claras e um modo simplificado para quem tem dificuldade com telemóveis. Fácil para todos, incluindo as pessoas mais velhas e as famílias que as ajudam.

Paga uma vez. Nunca uma subscrição.

Um só pagamento, sem renovações para controlar. Ganhamos dinheiro com aplicações que vale a pena comprar, não com os seus dados.

As nossas aplicações

PillBell

Android · 10 idiomas

Um alarme de medicamentos que toca mesmo: em ecrã inteiro, como um despertador, até a dose ser tomada. Para quem não quer falhar uma dose, seja um medicamento ou muitos, e para quem ajuda outra pessoa com os dela. Modo simplificado, a família toda numa só aplicação, uma lista de medicamentos em PDF para o médico e um registo de cada lembrete que tocou a horas.
