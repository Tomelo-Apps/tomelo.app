Vos données

Pour savoir ce que nous détenons à votre sujet, ou pour le faire supprimer, écrivez à support@tomelo.app. En pratique, nous ne détenons que les e-mails que vous nous avez envoyés. Nos applications gardent tout sur votre téléphone. Les détails figurent dans la politique de confidentialité du site.
