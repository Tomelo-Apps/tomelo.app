Paiements et remboursements

Nos applications sont vendues sur Google Play. Google gère le paiement, les reçus et les remboursements. Pour demander un remboursement, utilisez la page de remboursement de Google Play. Si quelque chose ne va pas dans l'application elle-même, dites-le-nous aussi, pour que nous puissions le corriger.
